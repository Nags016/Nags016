## 🛩️ About Me

- 🔭 Building **GPS-denied autonomous navigation** — OpenVINS visual-inertial odometry fused into **PX4** via ROS 2 on Raspberry Pi 5, currently in real-flight testing
- 🤖 Author of **AeroForge** — an agentic flight engineer that turns natural-language drone missions into PX4 SITL-validated policies *(Google All Things Agentic Hackathon 2026)*
- 🏆 **AIR 1 @ SAEINDIA Aerothon 2025** and **AIR 2 @ SAEISS ADDC 2026** with Team aeroKLE
- 🧭 Working at the intersection of perception, control, embedded compute and agentic AI
- ✍️ Sharing clean setup guides — my PX4 + ROS 2 + Gazebo guide is community-tested at ⭐4
